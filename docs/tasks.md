  - 완료 기준: gemma, glm 단가로 계산하는 단위 테스트 통과

- [ ] **T1-3. 점검·다시 추천 루프** (스펙 4.4)
  - 완료 기준 (가짜 LLM으로 TDD):

    - 나머지 위반의 `regenerate`를 중복 없이 모아 그 칸만 다시 요청한다
    - 최대 3회. 넘으면 식단표를 내보내지 않고 위반 원인을 돌려준다
    - 사용자 칸 수정 요청이 실패하면 수정 전 식단표를 그대로 둔다
  - 선행: T1-1

- [ ] **T1-4. 한도 초과 처리** (스펙 11.3)
