# 무료 티어에서 올릴 때 바꿀 것

## Workers Paid로 올릴 때

유료에서는 무료 할당을 넘어도 호출이 실패하지 않고 초과분이 과금된다. 그래서 안전선이 막는 대상이 "모든 사용자의 실패"에서 "청구 금액"으로 바뀐다. 아래 중에서 정한다.

1. **안전선을 비용 상한으로 바꾼다 (추천).** `GLOBAL_DAILY_NEURON_LIMIT`를 "하루에 쓸 수 있는 돈 ÷ Neuron 단가"로 다시 계산한다. 막는 범위와 진행 중 요청 허용은 그대로 둔다.
2. **안전선을 끈다.** 대신 Cloudflare 대시보드의 사용량 알림을 켠다. 사용자 제한(30회)은 남겨서 한 사람이 비용을 몰아 쓰지 못하게 한다.
3. **값을 환경 변수로 뺀다.** 지금은 상수다. 요금제가 자주 바뀔 것 같으면 `wrangler.jsonc`의 `vars`로 빼고, 없을 때는 지금 값을 기본으로 쓴다.

함께 볼 것:

- 사용자 하루 메시지 수: 유료에서는 비용과 남용 방지 기준으로 다시 정한다.
- 안내 문구: 안전선 문구("몇 시간 뒤")는 24시간 창을 전제로 한다. 비용 상한을 날짜 기준으로 바꾸면 "오전 9시 이후"처럼 시각을 다시 말해도 된다. 사용자 횟수 문구는 날짜 기준이라 그대로다.
- 카운터 기간: 유료 할당이 날짜 기준이면 `usage_hourly` 합산 창을 날짜로 바꿀지 정한다.
- 스펙 11.3의 한도 초과 처리(`QuotaExceededError`)는 유료에서는 거의 나오지 않는다. 남겨 둬도 해는 없다.
- 1회 사용 예산(스펙 11.2)과 모델 선택: 비용이 허락하면 더 큰 모델을 평가 세트로 다시 비교한다.
- 이 문서와 스펙 11.2·11.4를 새 값으로 고친다.
