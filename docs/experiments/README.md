# 실험 기록

실제 모델(Workers AI)을 부른 실험과 측정을 남긴다. 스펙 11.5는 결정에 쓴 요약이고, 이 폴더는 그 근거(방법, 원본 결과, 안 된 시도)다.

- 같은 실험을 다시 돌리기 전에 여기부터 본다. 무료 한도(하루 10,000 Neuron)를 아끼기 위해서다.
- 모델, 프롬프트, 규칙을 바꾼 뒤 "예전엔 어땠지?"를 비교할 때 쓴다.
- 원본 결과는 `data/`에 둔다. 결론에 쓴 실행만 골라 작은 JSON으로 남긴다. 평가 세트의 전체 결과(`evals-results/`)는 git에 넣지 않는다.
- `data/`의 식단표는 `src/core/experiments-recheck.test.ts`가 지금 `checkPlan`으로 다시 점검한다. 규칙을 바꾸면 예전 실험 결과가 어떻게 판정되는지 이 테스트에서 바로 보인다.
